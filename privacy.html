Privacy Policy

Last updated: 26 November 2026

This policy covers Schnoeddel Tech Uploader (home page), a private tool used by the owner of the Schnoeddel Tech YouTube channel to publish that channel's own videos.

Who uses it

Only the channel owner. The tool is not offered to the public and has no other users.

What data it accesses

With the owner's permission, the tool uses the YouTube Data API to upload videos to the owner's channel, set and read back their title, description, tags, thumbnail, visibility, audience and content-declaration settings, check upload processing status, and read the channel's own videos and comments. It does not access any other Google service and does not access anyone else's account.

How data is used and stored

Data obtained through YouTube API Services is used only to publish and manage the owner's own videos. It is not sold, shared with third parties, used for advertising, or used to train AI models. The sign-in authorization (OAuth token) is stored by Composio, the integration service that makes the API calls on the owner's behalf. Video files and metadata stay on the owner's own computer.

Google policies

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in Google Account permissions or through the Google security settings page. Revoking access stops all further API calls.
